# 学年综测附加分申报助手 · 使用手册

> **一句话介绍**：班长发来一堆几千行的加分来源表，这个工具帮你把「你的所有加分记录」一条条找出来、
> 按学校规则算好总分、填进学校下发的申报表，再为每条加分配一张"标明你在原表第几行"的证据截图，
> 最后整理成一个可以直接提交的文件夹。
>
> 已在 2025-2026 学年北京语言大学国传院真实数据上完整跑通（检索零漏检、申报表恰好一页）。

**这本手册怎么用**——两条路线二选一：

- **路线 A（推荐）**：让 AI 助手替你跑全部命令，你只负责回答问题和最终核对 → 看**第 1 章**，5 分钟上手；
- **路线 B**：自己在命令行里一步步跑 → 从**第 2 章**开始按顺序做。

不管哪条路线，材料都这样准备：**把班长发的所有来源表（xlsx / xls / docx）和学校下发的申报表模板放进同一个文件夹**。

## 1. 路线 A：让 AI 助手替你做（推荐）

### 1.1 首选 WorkBuddy

这个工具包就是按 WorkBuddy 的技能规范做的：放进去能被自动识别，AI 会替你跑命令、主动停下来向你提问，你基本只负责"回答 + 签字"。

**第 1 步 · 装技能**：把整个 `extra-points-filing` 文件夹放进 WorkBuddy 的技能目录
`~/.workbuddy/skills/`，然后新开一个对话。

**第 2 步 · 发指令**（照这个模板说，把引号里的内容换成你的）：

> 我的姓名是「姓名」，学号是「学号」，班级「如 24xx1班」，学院「如 国际政治与传播学院」，学年「如 2025-2026」。
> 请按 extra-points-filing 技能，读取文件夹「材料文件夹的完整路径」，帮我完成附加分申报表和全部来源截图。

**第 3 步 · 配合确认**：AI 会在三个地方停下来问你，逐个回答即可——
1. 身份信息与材料是否齐全（学号姓名对不上时它会拒绝继续，这是保护你）；
2. 规则歧义，比如集体荣誉折不折半——它会**把两种口径各自的总分都算给你看**，由你选；
3. 输出前让你确认"已录入 / 已排除 / 存疑"三张清单，就这些了吗。

**第 4 步 · 核对签字**：收到交付文件夹后，按 **7.4 节的清单**核对一遍，本人签名后提交。

### 1.2 用别的 AI 助手

| 助手类型 | 怎么接 |
|---|---|
| Codex、Claude Code 等终端型 | 把整个文件夹放进项目，指令写明：**"先读 SKILL.md，严格按其流程执行"**，它们会用自带的命令行跑脚本 |
| 豆包办公等对话型 | 上传 `SKILL.md` + `examples/` 三份样例，让 AI 帮你写配置文件、解读检索结果；具体命令由你按路线 B 在自己电脑上跑 |

### 1.3 无论用哪个 AI，三件事必须你亲自把关

1. **身份信息由你提供**：姓名、学号、班级、学院、学年，缺一不可；
2. **两可的判断由你拍板**：任何有两种解释的规则（折不折半、算哪一类），AI 会摆出分值后果，你选一个；
3. **提交前最后核对**：AI 给的三张清单（已录入 / 已排除 / 存疑）逐条过一遍。

## 2. 路线 B · 准备工作（只做一次）

### 2.1 安装 Python

1. 打开 `python.org/downloads`，点黄色按钮下载安装包；
2. 双击安装，**务必勾选页面底部的 "Add Python to PATH"**，再点 Install Now；
3. 验证：按 `Win + R`，输入 `cmd` 回车，打开黑色命令行窗口，输入 `python --version` 回车——显示 `Python 3.10` 以上版本号即成功。

### 2.2 安装依赖包

命令行里输入（路径换成你实际存放技能文件夹的位置）：

```
pip install -r "C:\你的路径\extra-points-filing\requirements.txt"
```

最后出现 `Successfully installed …` 就是装好了。

### 2.3 确认 Excel

随便双击打开一个 xlsx 能正常显示即可。**没有 Excel 也能用大半功能**：检索、填表（加 `--skip-recalc` 参数）、自检（配置里关页数检查）都行；只有"截图"一步做不了，可以留到任何一台装了 Excel 的 Windows 电脑上补做（几分钟）。

> 小技巧：后面所有命令都假设你已进入技能文件夹。在命令行输入
> `cd /d "C:\你的路径\extra-points-filing"` 回车即可。macOS / Linux 用户把命令里的 `\` 换成 `/`。

## 3. 第 1 步：检索——从一堆表里找出你的所有记录

命令行运行（引号里的内容换成你的）：

```
python scripts\scan_sources.py --root "D:\附加分来源" --name "张三" --sid "202400000001" --clazz "24xx" --out hits.txt
```

| 参数 | 必填 | 填什么 |
|---|---|---|
| `--root` | ✅ | **来源表所在的文件夹**（不是单个文件，脚本会递归扫全部 xlsx/xls/docx） |
| `--name` | ✅ | 姓名全名 |
| `--sid` | ✅ | 学号全号 |
| `--clazz` | 建议 | 班级关键词，如 `24xx`，用来找"全班都有"的集体荣誉 |
| `--extra` | 可选 | 别名、曾用名等补充精确匹配词，逗号分隔 |
| `--out` | 可选 | 把结果同时存成文本文件 |

**成功标志**：命令行打印出 A / B / C / D 四个区的结果，无红色报错。

**结果怎么读：**

| 区 | 意思 | 怎么处理 |
|---|---|---|
| A 个人命中 | 确定是你的记录 | 直接进入申报候选 |
| B 疑似命中 | "碰巧像你"的行（别人学号的后四位、表格里的序号） | 逐条看一眼排除掉，别偷懒 |
| C 候选集体条目 | 按班级关键词匹配到的行 | 从中挑出"全班都有"的荣誉（如优秀班集体） |
| D XML 兜底 | 脚本对文件内部的复核计数 | 某文件计数比 A 区多 → 该文件有漏检，必须人工打开找一遍 |

**为什么不会认错人**：脚本把搜索词分三档——姓名全名、学号全号是"精确词"，命中即认定是你；
名字片段、学号后 4 位只是"模糊词"，命中只进疑似区等人工排除；班级词只能找集体荣誉。
实测学号后三位 `123` 就撞上过序号列和别人的学号，所以这个设计必不可少。

**A 区一条都没有？** 别急着放弃：① 看 D 区有没有文件被标记漏检；② 检查表里是否用了曾用名/昵称（可用 `--extra` 补）；③ 手动 Ctrl+F 再确认一次。真没有就只能找主办方开证明。

## 4. 第 2 步：归类算分（需要你动脑的一步）

这一步没有脚本，因为规则是学校的、判断是你的。**产出一张"条目清单"**，每条写清：
`项目名称 / 级别 / 个人还是集体 / 分值 / 来源（哪个文件、哪个工作表、第几行）`。
后面填表和截图的配置全靠它。

**分值上限速查**（以北语为例，用前对照你们学校的《综合素质测评办法》）：
总分 10 ｜ 学术 4 ｜ 文体 3 ｜ 荣誉 3 ｜ 志愿 2 ｜ 其他文章 1。

**最容易算错的"不累计"规则：**
同类不同级别只按最好成绩；同一比赛多个奖项只按最好成绩；多个干部职务只取最高；
比赛"参与奖"不受限；献血 0.2 分/次上限 2 次；其他学院的活动只认学术类和志愿类；
**集体荣誉成员按分值 1/2 加分**（高频争议点，见下）。

**遇到这 4 种情况必须停下来确认，别自作主张：**

1. **集体荣誉折不折半**——先查学院汇总表表头备注、班级群通知；两种口径经常打架
   （实测学院表写折半、班级通知写全额），把两边各自的总分算出来，让本人或班长定，并在交付说明里留痕；
2. **同一荣誉在两张表里出现两次**——对比名称、时间、发奖部门，是同一项就只计一次；
3. **有没有班委、献血、表外活动**（论文、模联、校外竞赛）——来源表查不到，只能问本人；
4. **某项活动归哪个类别**——按来源表原分类，拿不准问本人。

查过但确认"没有"的事项也记下来（如"无班委、无献血、模联文件夹检索无记录"），
写进交付说明后班长就不用再问了。

## 5. 第 3 步：填表

### 5.1 先写配置文件（照抄样例，只改内容）

1. 用记事本打开 `examples\form_config.example.json`；
2. 另存为 `form_config.json`（放哪都行，建议放材料文件夹旁边）；
3. 按下表修改。

> **JSON 两条铁律**：所有键和文字都用英文双引号 `"…"` 包住；每行末尾的逗号一个不能多、一个不能少（最后一行不带）。改完保存。
> **单元格地址怎么看**：在 Excel 里点中一个格子，左上角名称框显示的 `B3` 就是地址。

| 字段 | 填什么 |
|---|---|
| `template` | 学校模板的完整路径 |
| `output` | 生成文件存到哪（文件名建议"姓名附加分申报表.xlsx"；脚本会**复制**模板再改，原模板不动） |
| `sheet` | 模板的工作表名（打开模板看左下角，多为 `Sheet1`） |
| `header` | 基本信息：`{"班级单元格": "内容", "姓名单元格": "内容", "学号单元格": "内容"}` |
| `header_text_format` | 学号单元格设为 `"@"`——按文本存，否则 202400000001 会显示成 2.02412E+11 |
| `rows` | 你的每条记录：`row` 是模板里的行号（看类别标题下面第一行是第几行），`values` 依次为项目名 / 奖项或职务 / 级别 / 个人或集体 / 分值 |
| `value_columns` | `values` 依次填进哪几列，一般是 `[2,3,4,5,6]`（即 B~F 列） |
| `empty_rows` | 模板里不用的类别行号列表，清空防止残留旧内容 |
| `subtotal_cells` | 各类别小计所在的单元格（如 `["G6","G9",…]`） |
| `total_cell` / `total_formula` | 总分放哪个格子、用什么公式（照模板原有公式抄） |
| `number_format` | **固定填 `"0.000"` 别改**——`0.###` 会把 1 显示成"1." |
| `print_area` | 打印范围，如 `"A1:G27"`（配合缩放到一页） |
| `recalc_with_excel` | 有 Excel 填 `true`：自动重算并保存，公式结果才会显示出来 |
| `pdf_out` | 页数检查用的临时 PDF 存放路径，**放系统临时目录，别放交付文件夹** |

### 5.2 运行

```
python scripts\fill_template.py --config "C:\你的路径\form_config.json"
```

没有 Excel 的电脑在命令末尾加 ` --skip-recalc`（代价：公式结果显示为空，用 Excel/WPS 打开时会自动算出来）。

### 5.3 成功标志

生成 `output` 指定的 xlsx，打开核对：基本信息、每条记录、总分都在；命令行最后报告 **PDF 页数 = 1**。
超过 1 页就去 Excel 里缩小行高或字号，再跑一遍。

## 6. 第 4 步：来源截图（仅 Windows + Excel）

把来源表里"你的那几行"裁剪成一张干净截图：保留原表表头（一眼看出这张表是什么性质）、
你的行用**橙色底纹 + 红色边框**标注、底部自动追加出处说明。每条加分一张。

### 6.1 写配置文件

同样照抄 `examples\shots_config.example.json` 另存为 `shots_config.json`，按下表改：

| 字段 | 填什么 |
|---|---|
| `base_dir` | 你的材料总文件夹 |
| `source_subdir` | 来源表所在的子文件夹名 |
| `out_dir` | 截图输出文件夹名（自动创建，建议"附加分来源截图"） |
| `dpi` / `col_min_width` / `col_max_width` / `max_col` | 清晰度和列宽微调，**照抄样例即可** |
| `tasks` | 每条加分一个任务，字段见下表 |

每个 task：

| 字段 | 填什么 |
|---|---|
| `src` | 来源文件名（只写文件名，不带路径） |
| `sheet` | 工作表名 |
| `last` | 原表总行数：打开该表按 **Ctrl+End**，光标跳到的格子所在行号就是 |
| `keep` | 截图里保留哪些行：**表头行 + 你的行**（全部填原表行号） |
| `hl` | 其中要标橙框的行：只填你的行 |
| `hdr` | 列标题在第几行 |
| `note` | 底部说明文字，写"对应申报表哪个条目" |
| `name` | 输出文件名，建议"序号_类别_条目_来源.png" |

> 行号一律填**原表的行号**。脚本内部删行时会自动从下往上处理，你不用管顺序。

### 6.2 运行与成功标志

```
python scripts\make_range_shots.py --config "C:\你的路径\shots_config.json"
```

跑完到 `out_dir` 里看：每条加分一张 PNG，你的行有橙底红框，底部有"来源：文件 〉 工作表 〉 原表第 n 行"。

## 7. 第 5 步：自检、清理与打包

### 7.1 自动自检

照抄 `examples\check_config.example.json` 另存为 `check_config.json`（改路径、行号和上限），
然后：

```
python scripts\final_check.py --config "C:\你的路径\check_config.json"
```

它会核对：姓名学号班级、每条分值、各类小计有没有超上限、打印是否一页、截图文件是否齐全。
没有 Excel 的机器在配置里加 `"verify_pages": false`（跳过页数检查）。

### 7.2 手工补两个文件

1. **`00_截图与申报表条目对照说明.txt`**（截图文件夹里第一份文件）——写清四块内容：
   ① 每条记录：名称 / 级别 / 个人或集体 / 分值 → 对应哪张截图 → 来源文件、工作表、原表行号；
   ② 存疑口径及最终处理方式；③ 已核对排除的事项；④ 提交前要做什么（签名、交给谁）。
   这份文件能让班长少问一半的问题。让 AI 助手代写即可。
2. **`姓名附加分申报表_预览.png`**——用 Excel/WPS 把申报表导出 PDF 后截第一页，或让 AI 助手生成。

### 7.3 清理 Excel 残留进程（Windows 必做）

跑过截图或重算后，后台可能残留无窗口的 EXCEL.EXE 偷偷吃内存（这是 Excel 自动化的老毛病，每跑一次就可能漏一个）。收工前跑：

```
python scripts\cleanup_excel.py --dry-run   ← 先看它准备结束谁，不会真动手
python scripts\cleanup_excel.py             ← 确认没问题再执行
```

放心：它只结束**没有窗口**的残留进程，你自己开着的 Excel 绝不会被误关。

### 7.4 最终交付清单

交付前照着勾：

- [ ] 申报表 xlsx：信息、条目、总分正确，打印恰好一页
- [ ] 预览图 PNG
- [ ] 截图文件夹：一条加分一张截图，橙框标的位置对
- [ ] 00 对照说明：每条都能对上"截图 + 行号"
- [ ] 文件夹里没有杂质（`.workbuddy/`、`~$` 开头的临时文件——有就是中间产物写错了地方，删掉）
- [ ] 交付文件夹整体重命名为"姓名 + 材料"之类，**本人签名**后提交

## 8. 常见问题 FAQ

**Q1：我不是北语的，能用吗？**
能。脚本和规则完全解耦——上限、折半这些只影响你在第 4 步里算出的分值；申报表模板不限北语版，配置里填哪个格子就填哪个格子。规则口径以你们学校的《综合素质测评办法》为准。

**Q2：来源表是老 `.xls` 格式、说明是 Word 文档，能检索吗？**
都能。`.xls` 和 docx 脚本都内置支持，不需要额外装库。

**Q3：可以只做检索、不填表吗？**
可以，第 3 步跑完就能收工。检索本身就是这套工具最值钱的能力。

**Q4：折不折半到底听谁的？**
工具不替你决定。把两种口径的总分都算出来，让本人或班长拍板，并在 00 说明里写明依据。

**Q5：电脑是 Mac / 没有 Excel，怎么办？**
检索、填表（加 `--skip-recalc`）、自检（关页数检查）都正常用；截图一步留到任何一台 Windows + Excel 的电脑上补做。替代方案见 `PORTABLE.md`。

**Q6：跑完感觉电脑变卡了？**
后台有 Excel 残留进程，跑一遍 `cleanup_excel.py` 即可。

## 9. 踩坑速查表

遇到问题先对号入座：

| 症状 | 原因与解决 |
|---|---|
| 学号显示成 `2.02E+11` | 学号列没按文本存 → 配置里 `header_text_format` 给学号单元格设 `"@"` |
| 分值 1 显示成 `1.` | 数字格式用错 → 固定用 `"0.000"` |
| 公式格子打开是空白 | 没重算回写 → `recalc_with_excel: true`；无 Excel 机器属正常，用 Excel/WPS 打开会自动算 |
| 标注错行 | 配置里填的行号不是原表行号 → 全部改回原表行号 |
| 导 PDF 报"该文档可能已被打开" | 文件被占用 → 关掉占用程序，或先跑 `cleanup_excel.py` |
| 交付文件夹里混进 `.workbuddy/`、`~$xxx.xlsx` | 中间产物写错位置 → 删掉；以后把 `pdf_out` 等临时路径指向系统临时目录 |
| JSON 配置一跑就报错 | 双引号没配对、逗号多写或漏写 → 逐行检查，或让 AI 帮你看 |
| 检索多出假记录 | 正常现象，弱标签命中本来就进疑似区 → 逐条人工排除 B 区 |
| 命令报"不是内部或外部命令" | 没进对文件夹或 Python 没装好 → 先 `cd /d` 进技能文件夹；重装 Python 并勾选 Add to PATH |
